# Search Algorithms Research Program

A Windows Forms application for comparing search algorithms using randomly
generated integer arrays.

## Requirements

- Windows
- Visual Studio with .NET Framework 4.7.2 targeting support

## Build and run

Open `paradygmaty-programowania.sln` in Visual Studio and build or run the
`paradygmaty-programowania` project. The search diagrams are copied to the
output directory automatically.

Choose an algorithm, set the array size and number of repetitions, then select
**Start** to run the comparison.
